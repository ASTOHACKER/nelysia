How to read 0.33 ms0.33 ms means successful requests took 0.33 milliseconds on average in that exact run. It includes the benchmark client's fetch scheduling, loopback networking, routing, handler work, serialization, response creation, and complete body delivery. It does not mean every request is exactly 0.33 ms or that the framework is universally faster.

Reproduce

BENCH_CASE=dynamic \
BENCH_DURATION_MS=3000 \
BENCH_CONCURRENCY=10 \
BENCH_REPEATS=3 \
npm run benchmark:bun

For a fair comparison, keep runtime versions, hardware, route, response shape, concurrency, warm-up, duration, and load generator identical.
