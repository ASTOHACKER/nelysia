# Nelysia v0.5.x Release Gates

The v0.5.0 feature set is shipped in the backward-compatible `v0.5.1` package,
which also contains the Bun route-compiled patch. The package is available from
the [v0.5.1 GitHub Release](https://github.com/ASTOHACKER/nelysia/releases/tag/v0.5.1)
as a tarball. The release is not called production-ready until the evidence
commands below have completed on the release candidate.

## Implemented contracts

- JWT uses an internal route-guard registry. Public routes do not inspect
  `Authorization`, import a verification key, or run JWT verification. HS256 is
  the only accepted algorithm; `issuer` and `audience` are optional checks.
- The compiler generates validators for deterministic built-in definitions in
  the documented subset. Standard Schema, transforms, custom runtime behavior,
  native `Response`, streams, and unsupported definitions use generic fallback.
  Build manifests report route-scoped fallback reasons.
- `@narudom96/nelysia/upload` exposes `FormData`/`File` uploads with limits and
  memory, disk, or custom storage adapters. `logger` provides typed redacted
  request logging. `timeout` provides a deadline `AbortSignal` and defaults to
  HTTP 504. AbortSignal cannot stop synchronous JavaScript already executing.

## Reproducible gates

```bash
npm run typecheck
npm test
bun test
npm run package:build
npm run package:imports
npm run docs:check
npm run deployment:smoke
npm run framework:check
npm audit --omit=dev

# Repeatable local gate including the 1M and 10M request-count soaks
npm run release:check:v05

# Release load evidence: oha 1.16.0, 30s × 7 per workload
npm run benchmark:oha:release

# Separate JWT public/protected and invalid-token security evidence
npm run benchmark:jwt:release

# Functional soak gates
npm run soak:1m
npm run soak:10m

# Separate 24-hour production-readiness report
npm run soak:24h
```

The benchmark command records CPU model, core/thread count, Node, Bun, oha, OS,
concurrency, sample count, latency percentiles, throughput, and failures. Raw
runtime comparisons are valid only within the same runner and workload.

Completed evidence for the current release candidate:

- Core `oha` load results: [`benchmark-oha-v05-2026-09-14.md`](./benchmark-oha-v05-2026-09-14.md)
- JWT public/protected security matrix: [`benchmark-jwt-v05-2026-09-14.md`](./benchmark-jwt-v05-2026-09-14.md)
- Bun route fast-path patch: [`benchmark-route-fast-path-v051-2026-09-14.md`](./benchmark-route-fast-path-v051-2026-09-14.md)
- 1M/10M request-count soak: [`soak-v05-2026-09-14.md`](./soak-v05-2026-09-14.md)

The recorded JWT run completed 105 measured samples with zero functional
failures. These reports are technical evidence for the current host and fixture;
they do not establish a universal performance ranking.

The 1M and 10M gates require zero functional failures and a clean process exit.
The 24-hour gate additionally requires no crash, unhandled rejection, or
correctness failure. RSS changes caused by allocator/runtime behavior are
reported separately and are investigated for a continuing growth trend.

The 24-hour soak is intentionally deferred and remains the outstanding
production-readiness evidence gate. The original `v0.4.0` tag and the existing
`v0.5.1` tag are immutable. npm publication remains a separate release action
when the registry account is available.
