# Nelysia v0.1 Definition of Done

This is the stopping point for the first implementation. New features do not enter v0.1 after this checklist is green.

## Included

- Bun and Node HTTP runtimes
- Static, parameter, query, body, headers, HEAD, OPTIONS, and 405 routing
- Request-local context
- Before, after, and error lifecycle hooks
- Basic plugin composition and mounted sub-apps
- Body, params, query, header, and response validation
- Basic built-in schemas and Standard Schema adapter
- Cookies and set-cookie support
- Native `Response` and `ReadableStream` responses
- Body-size limit and malformed JSON handling
- OpenAPI document generation and endpoint plugin
- Basic client fetch helper
- Compiler inspection and conservative Bun fast paths
- Node/Bun build entrypoints
- Differential, integration, streaming, schema, lifecycle, and routing tests
- Reproducible local benchmark runner with warm-up and repeated samples

## Exit Commands

All commands below must pass from the repository root:

```bash
npm install
npm run typecheck
npm test
bun test
npm audit
npm run build -- ./examples/hello/app.ts --target bun
npm run build -- ./examples/hello/app.ts --target node
```

## Explicitly Deferred To v0.2

- WebSocket protocol and cross-runtime adapter contract
- Standalone source-to-source code generation
- Full type-level route inference and generated typed client
- OpenTelemetry exporters and tracing backend integrations
- Deno, Cloudflare, Vercel, Astro, Next.js, and other deployment adapters
- Database, authentication, GraphQL, AI, and framework integrations
- PGO, multicore workers, and long-running production soak qualification

These are planned work, not hidden requirements for v0.1.

## Release Rule

When the exit commands pass, v0.1 is complete. Performance claims remain benchmark-specific and must include runtime version, hardware, workload, concurrency, duration, and repeated samples.
